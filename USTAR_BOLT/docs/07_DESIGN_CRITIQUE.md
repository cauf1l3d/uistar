# 07_DESIGN_CRITIQUE — Hostile self-review (внешний Principal Product Designer)

Формат: находка → серьёзность → решение в финальной версии.

1. **Первая версия Home перегружала жёлтым** (CTA + статус-чипы + прогрессы). — HIGH → Жёлтый оставлен только в CTA «следующего шага», маркере текущего в навигации и заливке прогресса; статус-чипы перешли на левые цветовые кромки.
2. **Metric-карточки Executive выглядели как generic SaaS-дашборд.** — HIGH → Убраны спарклайны и декоративные иконки; каждая метрика получила текстовый «trend» с бизнес-смыслом; главный риск — словами, не графиком.
3. **Дашборды без действий** (ранний HR-обзор был «витриной»). — CRITICAL → Каждый блок обзора получил прямое действие: «Создать», «Дополнить», «Напомнить», «Список на ревизию» (RULE 16).
4. **Скрытая CTA на пути курса**: у current-шага кнопка терялась среди карточек. — HIGH → Current-шаг получил жёлтую точку с ореолом, золотую рамку карточки и единственную заливную кнопку.
5. **Moodle leakage в конструкторе**: ранние подписи «активность», «SCORM-пакет». — CRITICAL → Словарь заменён: урок/видео/практика/игра/проверка. Проверка grep-ом.
6. **Карточкизация всего** (списки сотрудников как карточки). — MEDIUM → Списки HR/менеджера переведены в таблицы с тонкими разделителями (RULE 05), карточки — только для группировок.
7. **Слабая мобильная версия таблиц.** — HIGH → Паттерн `table--collapse`: строки складываются в пары «метка—значение», нижняя навигация не перекрывает контент (padding-bottom 88px).
8. **Излишние радиусы в ранних макетах (12–14px).** — MEDIUM → Сведено к 4–8px по визуальной грамматике.
9. **Повторение данных**: прогресс ступени показывался на Home, в Career и в Skills одинаковым блоком. — MEDIUM → Home показывает только сводку и ссылку; Career — полный разбор; Skills — уровни без процентов ступени.
10. **Границы ролей**: «Команда» сотрудника выглядела как менеджерский дашборд. — HIGH → У сотрудника — только список коллег и наставничество; никаких прогрессов чужих просрочек.
11. **Доступность**: focus-стили отсутствовали на chip/quiz-option. — HIGH → Общий `:focus-visible` + tabindex/role для квиз-опций.
12. **AI-slop-паттерны** (градиентный hero на логине, декоративная «сфера»). — MEDIUM → Оставлен один сдержанный контурный круг-суперграфика с opacity .16 как брендовый знак, без градиентов.
13. **Enterprise-достоверность**: демо-данные были «Lorem». — MEDIUM → Все данные — доменные (пены, герметики, приёмка, кассовая дисциплина, реальная орг-структура ритейла).
14. **Слишком много уровней в HR-навигации** (3 уровня в ранней схеме). — HIGH → Сведено к 2: раздел → объект; вложенность передана хлебными крошками.

Остаточные известные слабости честно перечислены в README → KNOWN LIMITATIONS.
