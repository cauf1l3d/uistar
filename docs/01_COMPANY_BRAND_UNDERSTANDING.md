# 01_COMPANY_BRAND_UNDERSTANDING — Компания и бренд

## Компания
Express Market (expressmarket05.ru) — операционная компания розничной и оптовой торговли: стройматериалы, инструмент, крепёж, сантехника, электрика, лакокрасочные, хозтовары. Магазины, торговый зал, склад, логистика, корпоративные (B2B) продажи, закупки.

Следствия для продукта:
- Пользователь №1 — **линейный сотрудник в зале/на складе**, со смартфоном, между покупателями. Отсюда mobile-first и «один следующий шаг».
- Знание товара — операционная необходимость (тысячи SKU, десятки категорий). База знаний — не «вики», а рабочий инструмент консультации.
- Ошибка сотрудника = возврат, конфликт, потерянный клиент → обязательное обучение и регламенты имеют дедлайны и видимые риски.
- Карьерная модель реальна: стажёр → специалист → старший → руководитель смены. Лестницы — центральная сущность.

## Бренд-характер USTAR
Сильный, точный, практичный, индустриальный, статусный, современный, человечный. Не enterprise-бюрократия, не игривый edtech, не generic SaaS.

## Визуальный перевод характера
| Черта | Решение в UI |
|---|---|
| Индустриальный, собранный | Графитовый shell (#202020), тонкие линии, плотная типографика, радиусы 4–8 px |
| Статусный | Один акцент — фирменный жёлтый #EBC500. Только для: current / selected / primary action / progress / identity |
| Практичный | Светлая «бумажная» рабочая область (#F4F4F1) для чтения и таблиц; контраст, а не тени |
| Человечный | Прямой короткий tone of voice, персональные приветствия, понятные статусы («Осталось 1 обязательное обучение») |
| Технологичный | Manrope (UI) + Montserrat (заголовки), табличные цифры в метриках, чёткие статусные цвета |

## Референсы (Reference Strategy, RULE 32 — не копировать целиком)

### Duolingo
- **USE:** одна явная следующая ячейка пути; логика completed/current/locked; ощущение непрерывного прогресса.
- **DO NOT COPY:** маскоты, мультяшность, стрики ради стриков.

### Axonify / eduMe (frontline-обучение для ритейла)
- **USE:** мобильный приоритет для «полевых» сотрудников; микро-форматы уроков (6–15 мин); привязка обучения к рабочим задачам смены.
- **DO NOT COPY:** геймифицированные баллы как самоцель, лента «активностей».

### 360Learning
- **USE:** навыки и внутренние знания как граф; понятие content gap; corporate learning architecture (роль ↔ навык ↔ материал).
- **DO NOT COPY:** generic SaaS-стилистика, перегруженные дашборды.

### Sana
- **USE:** редакционная ясность, спокойная плотность, простота авторинга для HR.
- **DO NOT COPY:** AI-first эстетика, «магические» паттерны.

### Эквио / iSpring Learn (российский корпоративный ритейл-сегмент)
- **USE:** модель «в полях»: назначения с дедлайнами, простые статусы, мобильные сценарии для торговых команд.
- **DO NOT COPY:** визуальная нейтральность «под всех клиентов» — USTAR обязан выглядеть как собственный продукт.

### Индустриальные tool-бренды (DeWalt/Hilti как культурный код жёлто-графитовой гаммы)
- **USE:** уверенный контраст жёлтого на графите, инженерная лаконичность, ощущение профессионального инструмента.
- **DO NOT COPY:** агрессивную промо-графику, капс-плакатность в рабочих экранах.

## Tone of Voice (закреплено)
Коротко, уверенно, по делу: «Следующий шаг — проверка знаний», «Осталось 1 обязательное обучение». Запрещены канцелярит и мотивационная патетика.
