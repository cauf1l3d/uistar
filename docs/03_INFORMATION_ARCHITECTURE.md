# 03_INFORMATION_ARCHITECTURE — Информационная архитектура

## Доменная модель (ядро продукта)

```text
Сотрудник → Должность → Ступень → Требуемые навыки (уровни)
   → Материалы/Обучения (шаги: урок | практика | проверка | игра)
   → Подтверждённый уровень → Готовность → Следующая ступень
```

Материал — единственная копия знания (RULE 09). Связи: материал ↔ навык(и) ↔ ступень(и) ↔ обучение(я). Назначение — автоматическое через должность/ступень; ручное — исключение.

## Карта разделов по ролям

### Сотрудник (mobile-first)
```text
Главная            — следующий шаг, статусы, продолжить обучение
Обучение           — активные / обязательные / завершённые
  └ Путь обучения  — шаги done/current/locked
      └ Урок / Практика / Проверка (activity shell, quiz shell)
Знания             — назначенное + каталог категорий
  └ Категория → Материал
Развитие           — лестница, ступень, требования, навыки
  └ Мои навыки
Команда            — коллеги смены, наставничество
```

### Руководитель (= сотрудник + Team)
```text
Команда
  ├ Исключения (просрочки, риски)
  ├ Готовы к ступени (заявки на аттестацию)
  ├ Полный список
  ├ Профиль сотрудника (подтверждение практики, напоминания)
  └ Знания команды (покрытие, дефицит)
```

### HR Studio (desktop-first, максимум 2 уровня)
```text
Обзор              — метрики продукта, дефициты, очередь публикации, аудит актуальности
Навыки             — карта навыков → Навык (уровни, покрытие, люди)
Материалы          — библиотека (статусы: черновик/на проверке/опубликован/устарел) → Редактор
Обучение           — конструктор (шаги, связи, назначение)
Лестницы           — список → Редактор лестницы (ступени, требования, дефициты)
Сотрудники         — список → Карточка (должность, ступень, исключения)
```

### CEO / Executive
```text
Обзор              — готовность компании, обязательное в срок, резерв, зоны риска
Отделы             — drilldown: причины, что делается
```

### Technical Admin
```text
USTAR MODE ⇄ TECHNICAL MODE (полный Moodle без редизайна)
```

## Принципы навигации
- Сотрудник: 5 пунктов, нижняя навигация на мобильном.
- HR: 6 пунктов, максимум два уровня вложенности.
- Хлебные крошки — только внутри разделов глубже 1 уровня.
- Поиск — глобальный по знаниям и обучению (TopBar).
